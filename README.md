# Nae Gallery

A simple local gallery for Android, designed for browsing and managing images and videos stored on the device.

## Features

- Browse local images and videos
- Full-screen media viewing
- Media information
- Delete and restore media
- Trash support
- Material 3 interface

## Tech Stack

- **Languages:** Java
- **Platform:** Android
